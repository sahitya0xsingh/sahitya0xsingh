# How this profile works

Three monochrome SVG cards (CRT grain, scanlines, glitch slices and SMIL motion) are generated by `scripts/generate.py` from public GitHub data.
The `refresh profile` workflow runs it every 6 hours and commits only when something changed.

| File | What it does |
|:--|:--|
| `scripts/term.py` | draws `assets/hero.svg` (halftone portrait, `whoami`, quote), `assets/records.svg` (split-flap records board) and `assets/skyline.svg` (one building per week, one lit window per contribution) |
| `scripts/github_api.py` | one GraphQL query for repos, merged PRs and the contribution calendar |
| `scripts/metrics.py` | streaks, active days, best day |
| `scripts/readme_sections.py` | rewrites the blocks between `<!-- NAME:START -->` and `<!-- NAME:END -->` in `README.md` |
| `data/profile.json` | name, headline, quote, the `now.txt` lines and the footer |
| `assets/photo.jpg` | source for the halftone portrait |

## Edit

- Change the text on the hero card in `data/profile.json`.
- Swap the portrait by replacing `assets/photo.jpg` with a head-and-shoulders photo.
- Pushing either file re-renders the cards automatically.

## Preview locally

```bash
pip install pillow
python scripts/generate.py --demo
```

Open `assets/hero.svg` in a browser. GitHub plays the same animations.
